Usage
=====

UPET integrates with the following atomistic simulation engines:

- **Atomic Simulation Environment (ASE)** — :ref:`usage_ase`
- **metatrain CLI** (batched evaluation on datasets) — :ref:`usage_metatrain`
- **LAMMPS** (including KOKKOS GPU support) — :ref:`usage_lammps`
- **i-PI** — :ref:`usage_ipi`
- **TorchSim** — :ref:`usage_torchsim`
- **GROMACS** — :ref:`usage_gromacs`
